## 一、本方案的设计逻辑（一条主线，不可跳步）

```
临床现象 / 临床未解决问题
        │  （凭什么说这是真问题？—— 自然史数据 + 指南留白 + 失败的临床试验）
        ▼
凝练科学问题（Why / What / How，主问题 + 3 个可证伪子问题）
        │  （把"病人身上的现象"翻译成"细胞里的事件"）
        ▼
病理生理过程 → 细胞生物学过程 → 分子事件
        │  （定位到一个**具体的、可敲除、可成药的节点**）
        ▼
机制解析（组学定位 → 遗传学因果 → 生化重构 → 人源体系确证）
        │
        ▼
可干预靶点 → 治疗模态选择（小分子 / siRNA / ASO / 蛋白工程 / mRNA-LNP / CAR-T）
        │
        ▼
动物有效性 + 安全性 → 伴随诊断 → 论文 / 专利 / 项目 / IND
```

**一条铁律**：每一个基础机制结论，都必须能回答"它改变了哪个病人的哪个决策"。无法回答的，不写进课题。

## 二、两项独立课题（一句话版本）

| | **课题一** | **课题二** |
|---|---|---|
| **标题** | 心肌细胞"自我靶化"（self-targeting）：NLRC5–免疫蛋白酶体–MHC-I 轴把心肌细胞从被动受害者变成主动抗原呈递靶标，驱动心肌炎慢性化与炎症性心肌病 | 心肌细胞线粒体外排物（exopher）**清除失能**：ADAM17–MERTK 剪切导致心脏驻留巨噬细胞"清道夫"功能衰竭，经 mtDNA–cGAS–STING 持续点火，决定急性心肌炎向慢性炎症性心肌病的转归 |
| **临床问题** | 病毒阴性慢性心肌炎 / 炎症性 DCM 为何在病原清除后炎症与心肌细胞死亡仍持续？为何广谱免疫抑制时好时坏？ | 为何约 20–30% 的急性心肌炎走向 DCM，而 50–75% 自愈？**急性期无法预测转归**，也没有改变转归的药 |
| **免疫臂** | 适应性免疫（抗原特异性 CD8⁺ 细胞毒 / 心脏 TRM） | 固有免疫（吞噬清除 + 胞内核酸感知） |
| **核心细胞生物学过程** | 蛋白质降解 → 抗原加工 → MHC-I 转录调控与表面呈递 | 自噬性外排 → 胞吞/efferocytosis → 溶酶体–代谢重编程 |
| **主靶点** | NLRC5（CITA）、PSMB8/PSMB9（β5i/β1i）、TAP1 | ADAM17–MERTK 剪切轴、GAS6、cGAS–STING |
| **治疗模态** | 心肌细胞定向 siRNA/ASO（NLRC5）＋ 已进入临床的选择性免疫蛋白酶体抑制剂（老药新用） | 工程化双功能蛋白（抗剪切 sMERTK–GAS6）＋ 髓系定向 mRNA-LNP ＋ STING 核酸药（并联灭火） |
| **伴随诊断** | 心肌 MHC-I/免疫蛋白酶体活性 + 外周 TCR 克隆性 | 血浆 cf-mtDNA + exopher 样囊泡负荷（急性期转归预测） |
| **干预时间窗** | 慢性期（发病 > 1–3 个月） | 急性期与"转归窗"（0–4 周） |

两者**无靶点重叠、无细胞主体重叠、无时间窗重叠、无诊断产品重叠**，可分别独立申报与发表（详见 `docs/05_两课题边界与区分度.md`）。

## 四、给评审人的"一页纸"摘要

**我们解决什么**：心肌炎没有任何一个被批准的疾病修饰疗法（disease-modifying therapy）。2025 ESC 指南把绝大多数治疗推荐停留在支持治疗与经验性免疫抑制，而迄今规模最大的随机试验（ARAMIS，抗 IL-1，n=117）是中性结果。问题不在"免疫抑制强度不够"，而在**我们抑制错了环节**：现有策略针对的是炎症的"放大器"（细胞因子），而非炎症的"点火器"与"靶标选择器"。

**我们提出什么**：心肌细胞不是旁观者。
- 课题一：它主动把自己的蛋白切成抗原肽、上调 MHC-I，为细胞毒 T 细胞**提供杀伤坐标**——这是慢性化的"靶标选择器"。
- 课题二：它持续外排损伤线粒体，一旦清除系统（MERTK）被剪切失能，这些线粒体 DNA 就变成**永不熄灭的点火器**。

**我们交付什么**：两个可成药靶点、两套治疗模态（核酸药 + 工程蛋白 + 老药新用）、两个伴随诊断原型，以及一条从小鼠到大动物的安全有效性证据链。

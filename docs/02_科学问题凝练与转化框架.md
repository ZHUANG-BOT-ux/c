# 第二部分　科学问题凝练与"临床→基础"的转化框架

> 本文件说明**方法论**：怎么把一个临床现象合法地嵌入细胞与分子生物学框架，而不是把临床词汇和分子名词硬拼在一起。两个课题都严格走这个流程。

---

## 2.1 四层转化模型

```
┌──────────────────────────────────────────────────────────────┐
│ L1  临床层（Clinical Layer）                                  │
│  现象 / 未满足需求 / 失败的治疗 / 分层失灵                     │
│  产出：一个用"病人"语言表述的问题                              │
└───────────────────────┬──────────────────────────────────────┘
                        │ 翻译规则①：把"结局"换成"过程"
                        ▼
┌──────────────────────────────────────────────────────────────┐
│ L2  病理生理层（Pathophysiology Layer）                        │
│  在组织/器官尺度：哪个过程失控？哪个稳态被打破？               │
│  产出：一个"稳态收支/反馈环"模型（不是分子，是系统）            │
└───────────────────────┬──────────────────────────────────────┘
                        │ 翻译规则②：把"系统失衡"落到"细胞行为"
                        ▼
┌──────────────────────────────────────────────────────────────┐
│ L3  细胞生物学层（Cell Biology Layer）                         │
│  哪一个保守的基本细胞过程？（蛋白降解、膜运输、自噬、吞噬、     │
│  核酸感知、代谢重编程、细胞死亡执行）                          │
│  产出：一个**可敲除、可示踪、可定量**的细胞过程                 │
└───────────────────────┬──────────────────────────────────────┘
                        │ 翻译规则③：找这个过程的"限速/开关节点"
                        ▼
┌──────────────────────────────────────────────────────────────┐
│ L4  分子–靶点–模态层（Molecular / Target / Modality Layer）    │
│  限速节点 → 可成药性评估 → 模态匹配 → 伴随诊断                 │
│  产出：靶点 + 药物形式 + 给药窗口 + 疗效/安全读出              │
└──────────────────────────────────────────────────────────────┘
```

### 三条翻译规则（防止"临床词 + 分子词"硬拼）

**翻译规则①：把"结局"换成"过程"。**
错误示范：「心肌炎会进展为扩心病」→「研究心肌炎进展为扩心病的机制」。这不是科学问题，是题目。
正确做法：问"**进展**本身是什么过程的持续？" → 心肌细胞死亡持续 + 纤维化替代 + 收缩单元净减少。于是"进展"被换成"**持续性心肌细胞净损失**"，这是一个有速率、有收支、可测量的过程。

**翻译规则②：把"系统失衡"落到"细胞行为"。**
持续性心肌细胞净损失 = 杀伤速率 > 保护/修复速率。
- 杀伤端：谁在杀？靠什么认出目标？ → **抗原呈递 → 细胞毒识别**（课题一）
- 点火端：炎症靠什么不熄灭？ → **DAMP 产–清收支失衡**（课题二）
这两条就是从 L2 到 L3 的两个合法分叉点，彼此正交。

**翻译规则③：在细胞过程中找"开关"而不是"参与者"。**
一条通路上几十个蛋白都"参与"，但只有少数是**转录总开关**或**限速酶/受体**，才值得做靶点。
- 课题一选 **NLRC5**：它是 MHC-I 抗原呈递通路的**反式激活总开关**（一次性调控 MHC-Ia/Ib、B2M、PSMB8、PSMB9、TAP1），而不是其中某一个结构基因 → 敲它才有系统性效应；且它是转录因子样分子，**天然适合核酸药物而非小分子**。
- 课题二选 **ADAM17–MERTK 剪切**：MERTK 是 exopher 摄取的关键效应受体（限速），而它的失活方式是**蛋白酶剪切**（可被阻断的、翻译后的、可逆的事件）→ 比敲下游信号更上游、更可干预。

## 2.2 科学问题凝练的筛选标准（五问法）

任何候选科学问题必须同时通过以下五问，否则淘汰：

| 筛选问 | 含义 | 课题一 | 课题二 |
|---|---|---|---|
| **Q1 临床锚定** | 它改变哪个病人的哪个决策？ | 病毒阴性慢性心肌炎 / ICI 心肌炎慢性期：是否、以何种方式做**不抑制全身免疫**的治疗 | 急性心肌炎第 0–4 周：**是否需要升级干预**（谁会进展） |
| **Q2 可证伪** | 有没有一个实验结果会否定假说？ | 心肌细胞特异性 *Nlrc5* 敲除**不**减少慢性期 CD8 浸润与心肌细胞死亡 → 假说否定 | 抗剪切 MERTK **不**降低心肌 cf-mtDNA 与慢性化 → 假说否定 |
| **Q3 机制新颖** | 是否只是已有结论换个器官？ | 心脏/心肌细胞中 NLRC5 功能为空白；"心肌细胞主动自我靶化"是新概念 | "exopher 清除失能作为心肌炎慢性化决定因素"为新概念；MERTK 的炎症性剪切在心脏未被研究 |
| **Q4 可成药** | 终点是否是一个可以做成药物的节点？ | NLRC5 → siRNA/ASO；PSMB8 → **已进入临床 II 期的选择性免疫蛋白酶体抑制剂**（老药新用） | ADAM17–MERTK 界面 → 工程蛋白 / 抗体；STING → 核酸药；髓系 mRNA-LNP 补充 |
| **Q5 可测量到人** | 机制能否变成人身上的一个读出？ | 心肌 MHC-I/免疫蛋白酶体活性 + 外周 TCR 克隆性 | 血浆 cf-mtDNA + exopher 样囊泡负荷 |

## 2.3 两个课题的"分叉树"（为什么只有这两个，且必须是两个）

从同一个 L2 命题出发：**"持续性心肌细胞净损失 = 杀伤速率 > 保护/修复速率"**

```
                持续性心肌细胞净损失
                        │
        ┌───────────────┴────────────────┐
        │                                │
  【为什么被杀？】                   【为什么炎症不退？】
  杀伤的"靶标选择"问题              炎症的"燃料供应"问题
        │                                │
  适应性免疫：抗原特异性              固有免疫：核酸感知
  CD8 TRM 需要"坐标"                 需要持续的 DAMP 池
        │                                │
  坐标由谁提供？                     DAMP 池由什么决定？
  → 心肌细胞自己（MHC-I 呈递）        → 产生 − 清除（收支）
        │                                │
  限速开关：NLRC5 / 免疫蛋白酶体       限速开关：MERTK（清除端）
        │                                │
   ▼ 课题一                           ▼ 课题二
  "自我靶化"                         "清除失能"
  Self-targeting                     Clearance failure
```

**为什么不能合并成一个课题**：
1. 两者作用于**不同的免疫臂**（适应性 vs 固有），实验体系与读出完全不同（TCR 测序/肽谱质谱 vs exopher 示踪/脂质组）。
2. 两者的**治疗时间窗相反**：课题一的干预在慢性期才有意义（抗原呈递程序被 IFN-γ 长期诱导后）；课题二的干预必须在急性期"转归窗"内（清除失能一旦造成纤维化替代就不可逆）。
3. 两者的**药物模态与递送靶细胞不同**（心肌细胞定向 vs 髓系定向），IND 路径、毒理关注点、CMC 全部独立。
4. 合并会导致任何一个阴性结果污染另一个——评审与审稿人都会认为机制不清。

**为什么又不能再多分一个**：第三条分叉（纤维化/成纤维细胞、遗传–炎症交互）确实存在，但：纤维化方向已有 FAP CAR-T 等成熟赛道（Science 2022），重复度高；遗传–炎症交互（DSP hot phase）需要大规模遗传分层队列，是 5 年以上的队列工程，不适合作为并行主课题 → 列为**储备方向**。

## 2.4 技术选择原则：只用"必要且不可替代"的技术

本方案明确**拒绝技术堆砌**。每项技术必须回答"如果不用它，哪个结论做不出来"。

| 技术 | 在本方案中回答什么**不可替代**的问题 | 用在 | 不用它会怎样 |
|---|---|---|---|
| snRNA-seq（心肌细胞核）+ scRNA-seq（免疫细胞） | 心肌细胞是否存在一个"抗原呈递程序高开"的亚群？它与哪些免疫细胞共存？ | 课题一 Aim1 | 只能做 bulk，无法分辨"是心肌细胞自己开了程序"还是"浸润细胞的信号被平均进去" |
| **配对 scTCR-seq** | 浸润 CD8 是否**克隆性扩增**、是否在慢性期维持同一克隆 | 课题一 Aim1 | 无法区分"抗原驱动"与"非特异性旁观炎症"——这是整个假说的立足点 |
| **空间转录组 / 高分辨成像质谱** | MHC-I^hi 心肌细胞与 CD8 TRM 是否在**空间上成对出现**（"杀伤微龛"） | 课题一 Aim1 | 相关性停留在"同一块组织里"，无法建立"面对面"的因果提示 |
| **MHC-I 免疫肽组质谱（immunopeptidomics）** | **真正被呈递的肽是什么** | 课题一 Aim2 | 抗原身份永远是推测；无法做抗原特异性干预与疫苗/耐受诱导的后续布局 |
| CellOracle 类**虚拟敲除**（GRN + in silico perturbation） | 在数十个候选转录调控子中，**哪个节点敲除后整个程序崩塌** | 课题一 Aim2 前置筛选 | 需要逐个做条件敲除小鼠（成本/时间不可行）；虚拟敲除把 N 从 ~30 降到 2–3 |
| **CMap / LINCS L1000 特征反转** | 哪些**已上市/已进入临床**的化合物能反转"自我靶化特征"或"清除失能特征" | 两课题 | 只能自己从头做小分子发现（10 年级别），失去快速转化机会 |
| **分子对接 + AlphaFold 复合物建模** | 候选小分子是否真的结合 PSMB8 的 β5i 口袋；工程蛋白 sMERTK–GAS6 的界面是否可行 | 两课题 | 化合物选择与蛋白设计靠盲试 |
| **hiPSC-CM（含患者来源）+ 自体/TCR 工程 T 细胞共培养** | 在**人**细胞中验证"心肌细胞抗原呈递 → 被杀"的因果 | 课题一 Aim3；课题二做人源对照 | 全部结论只在小鼠成立（G8 鸿沟） |
| **在体 exopher 示踪**（Myh6 驱动的线粒体荧光报告 + 流式/活体成像） | exopher **产生与清除**能否分别定量（收支） | 课题二 Aim1 | "收支失衡"假说无法被测量，退化为定性描述 |
| 巨噬细胞代谢组/脂质组（NAD⁺、衣康酸、胆固醇流出） | 清除失能是"吃不进"还是"消化不了" | 课题二 Aim2 | 把两种完全不同的机制混为一谈，选错靶点 |
| cf-mtDNA ddPCR + 囊泡流式 | 机制能否变成**血液检测** | 课题二 Aim4 | 没有伴随诊断，临床转化缺少分层工具 |

**明确不用的技术（及理由）**：
- 全外显子/全基因组测序大队列：属 G6 储备方向，不在本两课题关键路径上。
- CRISPR 全基因组筛选：两个课题的靶点已由文献 + 虚拟敲除收敛，全基因组筛选性价比低；仅在 Aim2 出现"虚拟敲除候选全部阴性"时作为备选（见风险对策）。
- Perturb-seq：同上，作为备选。
- 冷冻电镜：除非工程蛋白设计失败需要结构指导，否则不列入主线。

## 2.5 治疗模态的选择逻辑（不是"什么都试一遍"）

| 靶点性质 | 适配模态 | 不适配模态 | 本方案应用 |
|---|---|---|---|
| 大型支架/转录调控蛋白、无明确配体口袋 | **siRNA / ASO**（降低表达） | 小分子（无口袋） | NLRC5（课题一）、STING（课题二备选） |
| 酶，有明确催化口袋，已有临床分子 | **小分子抑制剂**（优先老药新用） | 核酸药（成本/递送不划算） | PSMB8/β5i 免疫蛋白酶体（课题一） |
| 受体功能"量不足"而非"活性过强" | **重组/工程蛋白补充**、**mRNA-LNP 补充** | siRNA/ASO（方向相反） | MERTK（课题二） |
| 蛋白–蛋白剪切事件 | **抗体 / 抗剪切变体 / 蛋白酶抑制** | ASO（无法阻断翻译后事件） | ADAM17–MERTK 剪切（课题二） |
| 需要清除特定细胞群 | CAR-T / CAR-M（含 mRNA-LNP 瞬时 CAR） | 小分子 | **本方案不把 CAR-T 作为主线**：心肌炎的问题是"错杀心肌细胞"，再引入一支杀伤军队风险/收益不利。仅在课题一 Aim4 作为"抗原特异性耐受/清除致病克隆"的**长期备选**（CAR-Treg 方向），并明确标注为探索性 |

**关于递送（G7）的现实主义立场**：
- 心肌递送是公认难题：血浆 ApoE 把 LNP 导向肝脏；LNP 内体逃逸效率仅 1–2%；心脏肌膜疏水屏障阻挡带负电核酸；AAV9 受预存中和抗体限制且难以重复给药。
- 因此本方案采取**三条并行、风险分散**的递送策略，而不是押注一种：
  1. **脂肪酸共轭寡核苷酸**（如二十二碳酸/DCA 共轭 siRNA 已被证明可功能性、安全地递送至骨骼肌与心肌）——成熟度最高，作为主路径；
  2. **心肌/髓系靶向配体修饰 LNP**（课题二髓系端可利用炎症时单核细胞天然摄取倾向，难度低于心肌细胞端）；
  3. **AAV9（Myh6/cTnT 启动子）**仅作为**机制验证工具**与小鼠/猪概念验证，不作为最终产品形式。

## 2.6 从"机制结论"到"临床决策"的回译表（Reverse translation）

这一步常被忽略，但是基金与转化评审最看重的地方。两课题必须各自填满这张表。

| 机制结论（若成立） | 对应的临床决策改变 | 需要的产品 | 监管路径起点 |
|---|---|---|---|
| **课题一**：心肌细胞 NLRC5–免疫蛋白酶体–MHC-I 程序是慢性期 CD8 杀伤的必要条件 | 慢性心肌炎/炎症性 DCM 从"要不要上激素+硫唑嘌呤"改为"查自我靶化评分 → 阳性者用靶向抗原呈递的治疗，且**不需要全身免疫抑制**" | ①心肌细胞定向 NLRC5 siRNA/ASO（新药）②选择性免疫蛋白酶体抑制剂适应证扩展（505(b)(2) 式/已上市分子新适应证）③自我靶化评分（LDT/IVD） | 适应证扩展先行（最快），新分子随后 |
| **课题二**：exopher 清除失能（ADAM17 剪切 MERTK）决定急性→慢性转归 | 急性心肌炎第 3–7 天测 cf-mtDNA/囊泡负荷 → 高危者在"转归窗"内接受清除修复治疗，而非一律观察 | ①抗剪切 sMERTK–GAS6 工程蛋白（新生物药）②髓系 mRNA-LNP（MERTK/TREM2 补充）③cf-mtDNA 转归预测试剂盒（IVD） | IVD 与药物并行（伴随诊断共同开发） |

## 2.7 伦理与合规前置声明

- 人体样本：EMB 剩余组织、心脏移植/供心弃用组织、外周血——均须 IRB 批准 + 知情同意；遵循《人类遗传资源管理条例》；基因/测序数据按国家人类遗传资源管理要求申报与存储。
- 动物：IACUC 批准；遵循 3R；CVB3 操作在 BSL-2；暴发性心肌炎模型须设定明确人道终点。
- 临床转化：首次人体试验前完成 Pre-IND 沟通；ASO/siRNA 类按核酸药物技术指导原则准备（含免疫原性、肝毒性、补体活化、脱靶评估）。

# 第一部分　领域文献调研与研究现状

> 范围：心肌炎（acute / chronic myocarditis）、炎症性心肌病（inflammatory cardiomyopathy, DCMi）、病毒性心肌炎、自身免疫性心肌炎、免疫检查点抑制剂相关心肌炎（ICI myocarditis）、巨细胞性心肌炎、嗜酸性心肌炎、扩张型心肌病（DCM）中的炎症成分、遗传性心肌病"热相"（hot phase）。
> 重点：**心脏免疫微环境如何导致心肌细胞损伤**。

---

## 1.1 疾病谱与定义框架：一个被"命名"切碎的连续体

临床上被分开命名的若干实体，在病理生理上是**一条连续轴**：

```
病原/药物/自身抗原触发
   │
   ├─► 急性心肌炎（acute myocarditis）
   │        ├─► 自愈（约 50–75%）
   │        └─► 持续性心肌炎症（chronic myocarditis）
   │                 │
   │                 ├─► 稳定性心功能不全（约 25%）
   │                 └─► 炎症性心肌病 / 炎症性 DCM（DCMi）（约 10–30%）
   │                           └─► 终末期心衰 / 移植 / 心源性死亡
   │
   ├─► 暴发性心肌炎（fulminant）→ 心源性休克（高急性死亡率，存活者转归分化显著）
   │
   └─► 特殊型：巨细胞性心肌炎、心脏结节病、嗜酸性（含 DRESS/EGPA）、ICI 心肌炎
```

**定义上的关键分歧（也是临床痛点的根源）**：
- WHO/ISFC 把"炎症性心肌病"定义为**心肌炎伴心功能不全**；而 ESC 的工作定义以免疫组化（CD3/CD45/CD68 细胞密度阈值）为准。
- 因此"同一个病人"在不同中心可能被诊断为"陈旧性心肌炎"、"炎症性 DCM"或"特发性 DCM"。**这不是术语洁癖问题——它直接决定病人是否获得免疫抑制治疗。**

**2025 ESC 心肌炎与心包疾病指南**（Eur Heart J 2025;46:3952）提出了类感染性心内膜炎的"确定/可能/可疑"分层诊断体系，并把心肌活检（EMB）明确收缩到"会改变治疗决策"的高危人群：急性心衰/心源性休克、疑诊巨细胞性心肌炎、心脏结节病、ICI 心肌炎、快速恶化的暴发型。这是重要进步，但同时**把慢性期病人的机制分型留在了空白区**。

## 1.2 自然史与流行病学：临床问题到底藏在哪一段

| 指标 | 数据 | 对研究设计的含义 |
|---|---|---|
| 未选择人群中的无并发症比例 | ~75% 自发缓解 | 任何干预都必须解决"不该治的人别治"的问题 → **分层是前提** |
| 活检确诊心肌炎的转归 | 约 50% 自发恢复；约 25% 持续稳定的心功能不全；10–25% 进展 | **真正的临床价值在那 25–30%**，而急性期无法识别他们 |
| 活检确诊者进展为 DCM | 文献区间 20–30% | 这是最明确的"可被改变的终点" |
| 青年猝死中的心肌炎占比 | 报道区间约 2–12%（取决于尸检标准） | 解释了为何 ESC 指南重点强化运动限制与风险分层 |
| ICI 心肌炎发生率 / 死亡率 | 发生率低（约 0.5–1.1%），但主要不良事件率高（历史数据死亡/严重事件可达 25–50%） | 低频高危 → 适合做**机制驱动的精准干预**，而非大样本流调 |
| DSP 相关 ACM 中"心肌炎样发作" | 约 5% 的 ACM 以心肌炎样发作起病；其中 **DSP 变异占 69%** | 遗传–炎症交互是真实的临床陷阱 |
| 急性心肌炎人群中心肌病基因罕见变异 | 约 8%（Lota et al., Circulation 2022），**DSP 为最常见** | "心肌炎"诊断里混入了遗传性心肌病 |

**从这张表读出的临床问题（不是综述式罗列，而是可操作的三个痛点）**：

1. **预后分层失灵**：我们不能在急性期告诉病人"你属于那 25%"。现有工具（CMR 的 LGE、T1/T2 mapping、hs-cTn 峰值、LVEF）反映的是**已经发生的损伤结果**，而不是**决定转归的机制状态**。
2. **慢性期机制黑箱**：病毒基因组阴性、仍有炎症细胞浸润、心功能持续下降的病人——炎症被什么维持？抗原是什么？没有答案就只能上广谱免疫抑制。
3. **治疗无靶**：没有任何针对心肌炎的疾病修饰药物获批。

## 1.3 心脏免疫微环境：细胞图谱的现状（我们知道什么）

### 1.3.1 髓系：驻留 vs 招募的二元结构已基本定型
- **CCR2⁻ 驻留巨噬细胞**（胚胎来源、自我更新）：维持稳态、促适应性重塑、抑制过度炎症、清除心肌细胞排出的损伤线粒体。
- **CCR2⁺ 单核来源巨噬细胞**：由单核细胞募集补充，产生炎性因子，驱动心衰进展、促纤维化、协助招募 T 细胞。
- **TREM2^hi 驻留巨噬细胞**是一个关键保护性亚群：
  - 在脓毒症心脏中通过清除心肌细胞排出的失功能线粒体维持心肌细胞稳态；TREM2 缺失导致自我更新受损、线粒体清除缺陷、炎症放大、心功能恶化（Nat Metab 2023）。
  - 在心梗中，TREM2⁺ 巨噬细胞经 SYK–SMAD4 下调 SLC25A53，减少线粒体 NAD⁺ 转运、增加**衣康酸（itaconate）**产生；衣康酸抑制心肌细胞凋亡、促成纤维细胞增殖（Cell Death Differ 2024）。
  - 结论：**"清除–代谢–抗炎"是一条已被证实的保护轴**。

### 1.3.2 T 细胞：从"浸润"到"克隆性、抗原驱动、组织定居"
- T 细胞系统被认为是自身免疫性心肌炎与炎症性心肌病的**主要始动者**（而非旁观者）。
- **α-肌球蛋白重链（α-MyHC）** 是优势心脏自身抗原；在实验模型与人类疾病中均可诱导致病性 T 细胞应答。α-MyHC 在心脏高表达但在胸腺中表达不足，是中枢耐受缺口的经典解释。
- **心脏 TRM（tissue-resident memory）**：心脏损伤会"播种"抗原特异性 T 细胞，这些细胞在心肌内获得定居表型（CD69⁺、PD-1⁺、CXCR6⁺），把**一次急性免疫激活连接到慢性、复发性炎症**。在 ICI 心肌炎中，损伤诱导的肌球蛋白特异性 TRM 被证明是驱动因素（PNAS 2024;121:e2323052121）。
- TRM 的维持需要**同源抗原 + IL-15**（DC 提供），两者非冗余。
- 慢性抗原刺激会把 TRM 推向组织定居性耗竭（TR-TEX）表型，而 TR-TEX 与 TRM 在本体发生与功能上不同（Nat Immunol 2025）。
- ICI 心肌炎中克隆性自身反应性 T 细胞针对肌肉抗原（α-肌球蛋白在心脏与骨骼肌共表达，解释了合并肌病的临床表型）。
- **Th17/IL-17**：IL-17 促进抗心脏抗体产生并推动向炎症性 DCM 进展；循环 Th17 水平在心肌炎中升高且与心衰严重度相关。
- **CD40** 被证明是一个免疫检查点调节者，通过激活与扩增 CCR2⁺ 巨噬细胞和 CD8 T 细胞放大心肌炎症。

### 1.3.3 B 细胞与自身抗体
- B 细胞参与心肌炎与心脏移植排斥；利妥昔单抗 B 细胞清除可改善炎症性 DCM 患者心功能（病例系列级证据）。
- 抗心脏抗体（anti-heart antibodies, AHA）在炎症性 DCM 中阳性率高，是免疫抑制获益的候选预测标志物——但**从未在前瞻随机试验中作为分层变量被验证**。

### 1.3.4 非免疫细胞：成纤维细胞与微循环
- scRNA-seq 显示 DCM 的差异表达**主要集中在心脏成纤维细胞群**；非心肌细胞异质性与新亚群在 DCM 中被反复鉴定。
- 过度的 IL-1β / IL-6 / TNF-α / 干扰素信号导致弥漫性心肌水肿、心肌细胞坏死与微血管功能障碍。
- 近期综述提出**免疫–微血管–免疫代谢（immuno-microvascular-immunometabolic）整合框架**作为驱动心肌损伤并向炎症性心肌病进展的中心机制。

## 1.4 心肌细胞损伤：死亡模式与"点火–放大"回路

### 1.4.1 多种程序性死亡在心肌炎中并存
| 模式 | 关键分子 | 在心肌炎中的证据 |
|---|---|---|
| 细胞凋亡 | Caspase-3/9、BAX | 经典，但"静默"死亡不足以解释持续炎症 |
| **焦亡（pyroptosis）** | NLRP3/AIM2–Caspase-1–GSDMD；Caspase-3–**GSDME** | ICI 心肌炎中 IFN-γ → Caspase-3 → **GSDME** 切割执行心肌细胞焦亡；GSDME 介导的 **mtDNA 释放激活 cGAS–STING**，通过 IFN 正反馈环放大炎症（Nat Commun 2024;15:6640） |
| 铁死亡（ferroptosis） | GPX4、ACSL4、系统 x_c⁻ | 在多种心肌损伤模型中被证实，心肌炎中证据渐增 |
| 坏死性凋亡（necroptosis） | RIPK1/RIPK3–MLKL | 与 DAMP 大量释放相关 |
| 直接病毒性溶解 | CVB3 2A 蛋白酶切割 dystrophin 等 | 病毒性心肌炎早期的"非免疫"损伤成分 |

### 1.4.2 DAMP 作为"把损伤翻译成炎症"的中枢
- 心肌细胞损伤释放 DAMP（mtDNA、HMGB1、ATP、S100、cf-dsDNA），作为内源性危险信号。
- **线粒体 DNA 是枢纽分子**：它同时是机制驱动者与线粒体应激的可测量指标，协调坏死性凋亡、焦亡与无菌性炎症。
- mtDNA 在胞质中有**两条感知路径**：cGAS–STING–TBK1–IRF3（I 型干扰素）与 NLRP3/AIM2 炎症小体（Caspase-1→GSDMD）。
- 已在糖尿病心肌病、放射性心肌损伤等多种模型中确证"线粒体损伤 → mtDNA 胞质泄漏 → cGAS–STING(–NLRP3) → 焦亡/炎症"。

### 1.4.3 心肌细胞的"主动排废"系统（关键但被低估）
- 心肌细胞通过**exopher**（1–5 μm、含 LC3 的膜性颗粒）主动排出失功能线粒体、蛋白聚集体与细胞碎片，该过程由心肌细胞自噬机器驱动，在心脏应激时增强（Nicolás-Ávila et al., Cell 2020）。
- 心脏巨噬细胞吞噬并降解 ISO 应激心肌细胞排出的 **>70%** exopher。
- **MERTK 是摄取线粒体物质的关键下游效应受体**。Mertk 缺陷心脏出现：损伤线粒体堆积、代谢受损、炎症小体激活、舒张功能障碍。
- **逻辑含义**：心肌细胞的"废物产生"与巨噬细胞的"废物清除"构成一个**收支平衡系统**。心肌炎中产废急剧上升；如果清除端同时失能，就会出现持续的胞外 DAMP 池——**这正是"病毒清除后炎症不退"的一个尚未被证明的机制候选**。

## 1.5 诊断现状与瓶颈

| 工具 | 能力 | 瓶颈 |
|---|---|---|
| hs-cTn | 敏感、可及 | 不特异；不区分机制；峰值与转归相关性弱 |
| CMR（2018 Lake Louise 修订标准） | 非侵入性、可定位、T1/T2 mapping + LGE | **测的是损伤结果**；对慢性低度炎症敏感性下降；无法给出免疫学分型 |
| FDG-PET | 对结节病/巨细胞性有价值 | 心肌葡萄糖代谢背景抑制困难；不特异 |
| EMB + 免疫组化 + 病毒 PCR | **唯一能给出组织学型与病因的手段** | 取样误差、侵入性、各中心标准不一；2025 ESC 已限缩适应证 |
| 抗心脏抗体 | 可提示自身免疫机制 | 标准化差，未进入随机试验分层 |
| 基因检测 | 可识别 DSP/TTN/FLNC 等"伪装成心肌炎"的遗传性心肌病 | 何时查、如何解读变异尚无共识；**近一半 DSP 变异青年患者最初被诊断为心肌炎** |

**瓶颈的本质**：现有全部诊断工具测的是**"有没有炎症、有多少损伤"**，没有一个测的是**"这个炎症是靠什么维持的"**。而后者才决定用什么药。

## 1.6 治疗现状：失败的试验教给我们什么

| 试验/证据 | 干预 | 结果 | 教训 |
|---|---|---|---|
| **ARAMIS**（n=117，CMR 确诊 + cTn 升高，72h 内随机，阿那白滞素 100 mg/d ≤14 天） | IL-1 受体拮抗 | **中性**：安全，但未增加无并发症天数 | ①针对**细胞因子放大器**而非点火器；②入组**低危、LVEF 保留**人群——天花板效应；③疗程短。**反对在未筛选的低危急性心肌炎中常规使用** |
| **TIMIC**（病毒基因组阴性的慢性炎症性心肌病，泼尼松+硫唑嘌呤 6 个月） | 广谱免疫抑制 | **阳性**：LVEF 显著改善 | **分层有效**：病毒阴性是关键前提。证明"机制分型 → 治疗获益"的原则可行 |
| ESETCID | 病因导向治疗 | 大体不确定 | 入组与终点设计困难 |
| 利妥昔单抗（炎症性 DCM 病例系列） | B 细胞清除 | 心功能改善 | 支持适应性免疫的因果地位 |
| IVIG（成人急性心肌炎） | 多机制免疫调节 | 证据不一致 | 机制不明的"广谱"策略难以复现 |
| **阿巴西普 + 芦可替尼**（ICI 暴发性心肌炎，30 例联合 vs 10 例激素，前瞻队列） | CD28 共刺激阻断 + JAK 抑制 | **死亡率显著下降** | **最有说服力的"机制驱动"范例**：直接打 T 细胞激活与细胞因子感知。随机试验（如 ATRIUM / NCT05335928 等）正在推进 |
| 抗病毒（干扰素-β，病毒持续者） | 清除病毒 | 部分改善 | 只覆盖病毒持续亚群 |

**综合教训（这是本方案两个课题的直接出发点）**：
1. 对全体急性心肌炎病人一刀切地抑制某个细胞因子 → 失败（ARAMIS）。
2. 按机制分层后给予免疫抑制 → 有效（TIMIC）。
3. 直接阻断 T 细胞活化通路 → 在最危重的机制明确人群中有效（ICI 心肌炎 abatacept + ruxolitinib）。

→ **结论：出路不是"更强的抗炎"，而是"识别并切断维持机制"。** 两个最可能的维持机制：
  - **适应性维持**：抗原持续被呈递 → CD8 TRM 持续杀伤（→ 课题一）
  - **固有维持**：DAMP 持续积累 → 核酸感知持续点火（→ 课题二）

## 1.7 研究空白（Gap 清单）

> 每条空白都标注：①为什么至今空白；②本方案由哪个课题承担。

| # | 研究空白 | 为何至今空白 | 承担 |
|---|---|---|---|
| **G1** | 免疫微环境研究以**免疫细胞为中心**，心肌细胞被当作被动靶点。心肌细胞自身的"免疫学身份"（抗原加工呈递机器、共刺激/共抑制配体、细胞因子分泌）在**人**心肌炎中缺乏系统刻画 | scRNA-seq 对心肌细胞取样极差（细胞体积大、易破），snRNA-seq 丢失胞质/膜蛋白信息；主流叙事偏向免疫细胞 | **课题一** |
| **G2** | **抗原身份未解决**。α-MyHC 是模型抗原，但人慢性心肌炎心肌中**真实被 MHC-I 呈递的肽谱（immunopeptidome）未知** | 需要克级心肌组织做 MHC 洗脱质谱，人样本量不足；缺乏替代体系 | **课题一** |
| **G3** | 急性→慢性**转归的决定因素**不清；缺乏机制驱动的预后分层标志物（CMR 参数是结果而非机制） | 需要前瞻性急性期队列 + 长期随访 + 机制读出，三者极少同时具备 | **课题二** |
| **G4** | **"无菌性炎症持续点火"的来源不明**：病毒清除后炎症为何持续？心肌源 DAMP（尤其线粒体源）的**"产–清收支"从未被定量** | 缺少在体 exopher 定量方法；清除端（MERTK/TREM2）研究集中在心梗与脓毒症，未进入心肌炎 | **课题二** |
| **G5** | 治疗策略"一刀切"失败，但**没有建立机制分型 → 治疗匹配的决策框架** | 缺乏可在临床标本上落地的机制读出 | 两课题（各自配套伴随诊断） |
| **G6** | **遗传–炎症交互**（DSP hot phase、TTN/FLNC）临床上已被发现，分子机制与治疗含义空白 | 需要遗传分层队列 + 免疫机制研究的交叉团队 | 储备方向（见 05 文档"延伸"） |
| **G7** | **心肌定向核酸药物递送**与**髓系定向递送**在心肌炎适应症下几乎空白；缺乏炎症微环境响应型递送 | 心肌递送本身是公认难题：ApoE 把 LNP 导向肝脏；心脏肌膜疏水屏障；AAV9 预存中和抗体且无法重复给药 | 两课题（分别承担心肌细胞定向与髓系定向） |
| **G8** | **模型–人鸿沟**：EAM / CVB3 不能充分反映人慢性炎症性心肌病；缺乏人源化 / 类器官–免疫共培养平台做靶点确证 | 建立 hiPSC-CM + 患者来源 T 细胞共培养体系门槛高 | 两课题共享平台（见 05 文档） |

### 1.7.1 本方案选择 G1/G2 与 G3/G4 的理由

- **G1+G2（课题一）**：这是**"靶标选择器"**问题。如果心肌细胞自身决定了"谁被杀"，那么干预心肌细胞的抗原呈递程序就是一个**不抑制全身免疫的治疗策略**——这解决了心肌炎治疗的核心矛盾（既要抗炎，又不能让病毒/肿瘤失控）。这一点对 ICI 心肌炎尤其关键：肿瘤患者不能接受全身免疫抑制。
- **G3+G4（课题二）**：这是**"点火器与灭火器"**问题，并且天然自带一个**急性期可测的生物标志物**（血浆 cf-mtDNA + exopher 样囊泡），直接回答"谁会进展"这个最硬的临床需求。

## 1.8 本领域已有工作与本方案的区分（避免重复劳动）

| 已有工作 | 已经做到哪 | 留给我们的空间 |
|---|---|---|
| ONX-0914（PR-957）在 CVB3 心肌炎（EMBO Mol Med 2018 等） | 免疫蛋白酶体抑制减轻病毒性心肌炎，但机制被归因于**抑制系统性炎症反应**（免疫细胞侧） | **未检验心肌细胞自身的免疫蛋白酶体/抗原呈递程序**；未做组织特异性遗传学因果；未鉴定肽谱；无慢性期与 ICI 模型数据 |
| NLRC5/CITA 作为 MHC-I 反式激活因子（Nat Cell Res 2012；Immunology 2021 等） | 在感染与肿瘤免疫中确立：反式激活 MHC-Ia/Ib、B2M、LMP2(PSMB9)、LMP7(PSMB8)、TAP1 | **心脏/心肌细胞中 NLRC5 的功能完全空白**；无心肌细胞特异性敲除表型；无核酸药物探索 |
| Nicolás-Ávila Cell 2020（exopher–MERTK） | 稳态与 ISO 应激下的清除机制；Mertk 缺陷表型 | **未进入心肌炎/炎症性心肌病**；未研究 **MERTK 的炎症性剪切失活（ADAM17）**；未做转归预测与治疗 |
| TREM2 在脓毒症心脏与心梗中的保护作用 | 清除线粒体、衣康酸介导保护 | 心肌炎语境缺失；未与 cGAS–STING 持续点火串联；未做成药 |

**小结：现状可以用一句话概括**——我们对心肌炎免疫微环境的**细胞构成**了解颇多，对**心肌细胞如何被杀**了解不少，但对**"炎症靠什么维持下去"**几乎一无所知；而正是后者决定了那 25–30% 走向扩心病的病人。

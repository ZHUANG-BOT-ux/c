# 第六部分　全链条规划：论文 · 专利 · 项目申请 · 转化落地

> 原则：**机制论文铺路 → 专利先行于论文 → 项目分级承接 → 诊断先落地、药物后跟进**。
> 纪律：**任何可专利内容，专利申请日必须早于论文投稿日**（含预印本、会议摘要、学位论文）。本文件 §6.3.1 给出强制时序。

## 6.1 论文布局

### 6.1.1 总体策略

- **先方法/图谱，后机制，再药物**：方法学与数据资产类论文周期短、引用高、为后续背书；机制论文冲高影响力；药物论文需安全性数据完整后发表。
- **每篇论文一个单独的结论**，不堆砌（避免"一篇大文章卡 3 年"的风险）。
- 两课题各出 **1 篇旗舰 + 3–4 篇支撑 + 1–2 篇综述/观点**。
- **综述/观点文章要早发**：在机制论文之前发表"概念类"综述/Perspective，用于**确立领域话语权与命名权**（"self-targeting"、"clearance failure / 产废-清废收支"）。这是低成本高回报的一步。

### 6.1.4 作者与贡献规则（避免后期纠纷，写进项目启动文件）

- 每篇论文在**启动时**确定第一作者、共同第一作者、通讯作者，并写入项目管理文档。
- 人样本库的提供中心按**样本贡献量 + 临床数据完整度**获得署名权（预先约定阈值，如提供 ≥10 例完整随访病例获共同作者）。
- 方法学论文（2-B）与数据资产论文（1-C）必须**公开数据**（GEO/PRIDE/ProteomeXchange），这是提升引用与领域话语权的关键，也是多数顶刊要求。
- 预印本策略：**仅在对应专利申请日之后**才允许上传 bioRxiv/medRxiv。

### 6.2.3 强制时序纪律（最常被违反，损失最大）

```
数据产生
   │
   ▼
① 发明披露（内部，48h 内填表）
   │
   ▼
② 可专利性快速评估（2 周内，与专利代理人）
   │
   ├─ 可专利 ──► ③ 撰写并提交首次申请 ──► ④ 取得申请号
   │                                              │
   └─ 不可专利 ──────────────────────────────────┤
                                                  ▼
                                      ⑤ 允许投稿 / 预印本 / 会议摘要
```

**红线**：
1. 任何会议摘要、口头报告、学位论文答辩、预印本，在提交前必须经专利检查。
2. 与外部单位（含合作医院、CRO、CDMO）交换未公开数据前，必须有 **CDA/MTA**，并明确知识产权归属。
3. 使用他人材料（如特定 iPSC 系、小鼠品系、化合物）前核查 MTA 中的**reach-through 条款**（避免成果被要求共享）。

### 6.3.2 申请书撰写要点（针对本方案的特殊性）

**课题一面上项目申请书的"立项依据"必须回答的三问**：
1. 为什么是 NLRC5 而不是 STAT1/IRF1？→ 答：虚拟敲除的网络坍塌分析 + NLRC5 是**专一**反式激活 MHC-I 模块（不像 STAT1 牵动全部 IFN 反应，敲 STAT1 等于全身免疫抑制，无治疗窗）。**这一"治疗窗"论证是本申请的最强论点。**
2. ONX-0914 既有研究是否已经做过？→ 答：既有研究把保护归因于**系统性炎症抑制（免疫细胞侧）**，未检验心肌细胞内在程序，未做组织特异性遗传学因果，未鉴定肽谱。我们用**骨髓嵌合实验**直接区分。
3. 心肌递送这么难，成药性是否空谈？→ 答：①机制结论本身独立成立；②脂肪酸共轭寡核苷酸递送心肌已有发表证据；③小分子（老药新用）作为并行主线不依赖递送突破。

**课题二面上项目申请书的"立项依据"必须回答的三问**：
1. "收支"如何测量？→ 答：Aim1.1 的双通道报告小鼠与 CI 指数（这是本申请的**方法学创新点**，要在摘要第一句就写出来）。
2. 与 Nat Commun 2024 的 GSDME–cGAS–STING 工作什么区别？→ 答：§4.3.4 的五维对照表（直接贴进申请书）。
3. 为什么认为清除失能是"决定变量"而非"伴随现象"？→ 答：Mertk^CR/CR 抗剪切敲入是**充分性**实验；*Mertk*×*Sting1* 上位性是**链条闭环**；人队列是**时序先于结局**的证据（d3–d7 预测 12 个月）。

### 6.3.3 两课题申报的"防撞车"规则
- 同一申请人不在同一年度申报两个内容相近的面上项目。
- 两课题的申请书中**必须互相引用并明确划界**（评审专家常同时看到两份）：在"与申请人其他项目的区别"一节直接贴 05 文档的 12 维矩阵。
- 重点项目申报时，把两课题作为**两个子课题**整合，并以"共享人样本库 + 两条独立免疫臂"作为整体性论证。

| **P4　NLRC5 siRNA/ASO** | 核酸药（新分子） | 课题一 Aim4.2 | 长（7–10 年到 IND） | 高（递送） | 与核酸药企**早期联合开发**（对方出递送平台，我方出靶点与机制）→ 共同申报专项 |

**排序逻辑**：用 P1 的快速落地产生现金流与影响力，为 P3/P4 的长周期开发争取时间与资源；P2 是"机会型"项目，成本低、一旦合作成功回报快。

### 6.4.2 IND-enabling 包（以 P3 为例的标准清单）

| 模块 | 内容 | 执行方 |

| 药学（CMC） | 细胞株构建、工艺开发、放大、制剂、质量研究、稳定性、参比品 | CDMO |

### 6.4.3 监管策略要点

- **适应证定位**：优先选择"小而明确、无替代疗法、终点清晰"的人群作为首个适应证——例如**暴发性心肌炎/巨细胞性心肌炎**（罕见、病情重、终点硬），有利于获得**罕见病/孤儿药资格**（中国罕见病目录与审评政策、FDA Orphan Drug Designation、EMA Orphan Designation），并可能适用**附条件批准**或**优先审评**。
- **突破性治疗/快速通道**：若动物数据显示对暴发性心肌炎生存的显著改善，可申请中国"突破性治疗药物程序"与 FDA Fast Track。
- **伴随诊断共同开发**：P1 与 P3/P4 应作为"药物–诊断共同开发"申报，这是本方案结构上的优势（机制 → 标志物 → 富集入组），也是修正 ARAMIS 设计教训的直接体现。
- **终点选择的现实主义**：心肌炎的硬终点（死亡/移植）事件率低、随访长。因此必须早期与监管沟通**替代终点**（LVEF 变化、CMR LGE/T1-T2、cTn 归零时间、NT-proBNP、生物标志物），并准备"复合终点 + 无并发症天数（days alive and out of hospital）"类设计（ARAMIS 即采用此类终点，可借鉴其方法学而非其人群选择）。

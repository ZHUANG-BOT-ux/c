# 课题二　心肌细胞线粒体外排物（exopher）**清除失能**

## ADAM17–MERTK 剪切导致心脏驻留巨噬细胞"清道夫"功能衰竭，经 mtDNA–cGAS–STING 持续点火决定急性心肌炎向慢性炎症性心肌病的转归

---

## 4.1 L1 临床层：问题从哪来

### 4.1.1 临床场景

**场景 A（转归分叉）**
两位 32 岁男性，同一周入院，均为急性心肌炎：胸痛、hs-cTnI 峰值相近、CMR 均阳性、LVEF 均约 45%。
- 患者甲：6 周后 LVEF 62%，完全恢复，无后遗。
- 患者乙：6 周后 LVEF 38%，3 个月时 30%，1 年后诊断炎症性 DCM，2 年后进入移植评估。
→ **临床医生在第 7 天无法区分甲和乙。** 没有任何现有指标（cTn 峰值、LGE 范围、T2、CRP、LVEF）能可靠做到。
→ 这是心肌炎领域最硬、最有商业价值、也最被低估的临床需求：**转归预测 + 转归改变。**

**场景 B（暴发性心肌炎存活者）**
25 岁女性，暴发性心肌炎，ECMO 支持 9 天后脱机，LVEF 恢复至 50%。出院后 4 个月 LVEF 再度下降至 35%，EMB 示持续炎症、病毒阴性。
→ 急性期"活下来"不等于"好了"。**存活者的慢性化是一个独立的、被忽视的临床问题。**

**场景 C（为什么抗炎失败）**
ARAMIS 试验（n=117）在 72 小时内给予 IL-1 受体拮抗剂，结果中性。
→ 如果炎症的"燃料"持续供应，关掉一个下游细胞因子就像在漏油的发动机上拧掉一个火花塞。**我们需要找到燃料本身。**

### 4.1.2 临床未满足需求

| 需求 | 现状 | 缺口 |
|---|---|---|
| 急性期转归预测 | 无机制驱动的标志物；CMR/cTn 反映已发生的损伤 | 需要**反映"持续点火状态"的动态血液标志物** |
| 改变转归的急性期干预 | 无；ARAMIS 中性 | 需要作用于**燃料供应端**而非细胞因子端的干预 |
| 暴发性心肌炎存活者的二级预防 | 无特定策略 | 同上 |
| 识别"该治的人" | 一刀切抗炎 | 需要**伴随诊断 + 药物同步开发** |

## 4.2 L2 病理生理层：从"结局"到"收支"

**命题**：急性心肌炎的转归 = 炎症能否在损伤停止后**自限性熄灭**。

熄灭失败的条件是什么？炎症需要持续的激活信号。病毒清除后（多数患者在 2–3 周内清除），持续的激活信号只能来自**内源性危险信号（DAMP）**。而 DAMP 水平不是由"产生"单独决定的，而是由**收支**决定：

```
组织 DAMP 池  =  ∫ ( 产生速率 − 清除速率 ) dt
```

**心脏在这件事上有一个独特而被低估的生理系统**（01 文档 §1.4.3）：
- 心肌细胞通过**自噬驱动的 exopher**（1–5 μm、含 LC3 的膜性颗粒）主动排出失功能线粒体与蛋白聚集体，应激时显著增强（Cell 2020）。
- 心脏巨噬细胞吞噬降解 ISO 应激心肌细胞排出的 **>70%** exopher；**MERTK 是摄取线粒体物质的关键效应受体**。
- Mertk 缺陷 → 损伤线粒体堆积 + **炎症小体激活** + 代谢受损 + 舒张功能障碍。
- TREM2^hi 驻留巨噬细胞同样清除心肌细胞排出的失功能线粒体，缺失则导致清除缺陷、炎症放大、心功能恶化（Nat Metab 2023）。

**L2 核心模型（本课题的原创命题）**：
> 急性心肌炎同时做了两件相反的事：
> **①产生端暴增**——心肌细胞在炎症/缺氧/细胞因子打击下大量外排损伤线粒体；
> **②清除端失能**——正是同一炎症环境（TNF-α/IL-1β 诱导 ADAM17 "sheddase" 活性）**剪切掉巨噬细胞表面的 MERTK**，并耗竭 CCR2⁻/TREM2^hi 驻留巨噬细胞池（被 CCR2⁺ 炎性单核细胞替代）。
>
> → 结果是一个**"产废剧增 + 清废瘫痪"的双重打击**，形成持续的胞外/胞内 mtDNA 池。
> → mtDNA 经 cGAS–STING 与 NLRP3/AIM2 两条路径**持续点火**，而这一点火**独立于病毒是否存在**。
> → **这就是"病毒清除后炎症不退"的机制候选，也是转归的分叉点。**

## 4.3 L3 细胞生物学层：定位到基本细胞过程

**对应的基本细胞过程：选择性自噬性外排（exophergenesis）→ 受体介导的胞吞/efferocytosis → 吞噬溶酶体降解 → 代谢重编程。**

把"清除失能"精确拆成三种**互斥的**细胞生物学故障（这一拆分决定了靶点选择）：

| 故障类型 | 细胞生物学定义 | 分子对应 | 对应干预 |
|---|---|---|---|
| **F1 "抓不住"** | 识别/系泊失败：桥接分子或受体缺失 | **MERTK 被 ADAM17 剪切脱落**；GAS6/PROS1 不足；TREM2 配体识别受损 | 抗剪切 MERTK、补充 GAS6、TREM2 激动 |
| **F2 "吃不进"** | 内化失败：细胞骨架/信号缺陷 | SYK、Rac1、PI3K 信号 | 下游，不优先 |
| **F3 "消化不了"** | 吞噬溶酶体成熟/降解失败，代谢负荷超载 | 溶酶体酸化、NAD⁺/线粒体代谢、胆固醇流出（ABCA1/LXR） | 代谢支持、LXR 激动 |

**为什么优先打 F1（MERTK 剪切）**（02 文档 §2.1 翻译规则③）：
1. MERTK 已被证明是心脏线粒体物质摄取的**关键限速效应受体**（Cell 2020）；
2. 它的失活方式是**蛋白酶剪切**——一个**翻译后、可逆、可被抗体/工程蛋白阻断**的事件，比敲下游信号更上游、更可干预；
3. 剪切产生的**可溶性 MER（sMER）本身是"诱饵受体"**，会竞争性结合 GAS6，进一步抑制剩余 MERTK 的功能 → **一次剪切造成双重打击**，放大效应强，干预收益高；
4. sMER 可在血液中检测 → **天然自带伴随诊断**。

### 4.3.4 与已发表的 GSDME–cGAS–STING 工作的明确切分（防重复）

Nat Commun 2024 已建立 ICI 心肌炎中的**胞内自放大环**：T 细胞 IFN-γ → Caspase-3 → GSDME 切割 → 焦亡 + **mtDNA 释放** → cGAS-STING → IFN 放大。

| | 已发表（Nat Commun 2024） | **本课题** |
|---|---|---|
| 关注的 mtDNA 来源 | 焦亡时心肌细胞**被动破裂**释放 | 心肌细胞**主动外排（exopher）**的生理性通路被劫持 |
| 关注的环节 | **产生端 + 胞内感知** | **清除端（巨噬细胞 efferocytosis）** |
| 细胞主体 | 心肌细胞 | **心脏巨噬细胞**（驻留 vs 招募） |
| 干预点 | GSDME / STING（下游灭火） | **ADAM17–MERTK（上游恢复清除）** |
| 疾病语境 | ICI 心肌炎 | **急性→慢性转归（含病毒性/暴发性）** |

→ 二者**互补而非重复**。本课题把 STING 阻断仅作为**并联的"灭火"对照与联合方案**，主线是"恢复清除"。这个区分必须写进所有论文与基金的"与已有工作区别"段落。

## 4.4 中心假说

> **假说（Clearance Failure Hypothesis）**
> 急性心肌炎中，炎症环境通过 **ADAM17 介导的 MERTK 胞外域剪切**（并伴 CCR2⁻/TREM2^hi 驻留巨噬细胞池耗竭）使心脏"清道夫"系统失能；与此同时心肌细胞 exopher 产生剧增。
> **"产废–清废"收支失衡**造成持续的 mtDNA DAMP 池，经 cGAS–STING（及 NLRP3/AIM2）**持续点火**，驱动炎症不熄灭、心肌细胞继续死亡与纤维化替代。
> **清除能力（而非初始损伤程度）是急性心肌炎转归的决定变量。**
>
> **治疗推论**：在急性期"转归窗"（约 0–4 周）内**恢复清除能力**（抗剪切 MERTK / 补充 GAS6 / 髓系补充 MERTK 或 TREM2），而非压制下游细胞因子，可以改变转归。
> **诊断推论**：血浆 **cf-mtDNA + sMER + exopher 样囊泡负荷** 构成"清除失能指数"，可在急性期预测进展。

### 4.4.2 三个可证伪的子假说

| 子假说 | 证伪条件 |
|---|---|
| **H1（收支可测且失衡）** 急性心肌炎中 exopher 产生↑ 而清除↓；膜 MERTK 下降、sMER 升高、组织/血浆 mtDNA 升高；且这些指标在"进展者"中显著更差 | 清除能力在进展者与恢复者之间无差异 → 假说否定 |
| **H2（因果：清除失能是必要/充分条件）** 髓系特异性 *Mertk* 缺失加重慢性化；**抗剪切 MERTK 敲入（MertkCR）**减轻慢性化；*Adam17* 髓系敲除表型同向 | 上述遗传操作无表型 → 清除端非决定因素 |

## 4.5 研究内容：四个 Aim

### Aim 1　建立"产废–清废收支"的在体定量方法，并在人与小鼠中证明失衡（对应 H1，G3+G4）

**这是本课题最关键也最难的一步：没有定量方法，"收支"只是修辞。**

**Aim 1.1 在体 exopher 示踪与双通道定量（方法学创新）**
- 工具小鼠：`Myh6-MerCreMer; R26-mt-Dendra2`（或 mt-Keima / MitoTimer / mito-mKate2）——**心肌细胞特异性标记线粒体**。
  - **产生读出**：心肌组织/心包液中游离的心肌细胞源荧光颗粒（1–5 μm）数量（流式 + 共聚焦 + 活体双光子）。
  - **清除读出**：心脏巨噬细胞（CD45⁺CD64⁺）内的心肌细胞源荧光信号比例（"已吞噬分数"）。
  - **收支指数定义**：`CI = (巨噬细胞内信号) / (总心肌源胞外信号 + 巨噬细胞内信号)` —— 一个 0–1 的清除效率指标。
- 验证：ISO 应激（已知阳性对照，Cell 2020）→ CVB3 / EAM / ICI 模型时间序列（d3、d7、d14、d28、d60）。

**Aim 1.2 清除机器的状态刻画**
- 流式 + 质谱流式：心脏巨噬细胞**膜 MERTK 密度**（胞外域抗体 vs 胞内域抗体双染 → 直接读出"剪切程度"）、TREM2、CD64、CCR2、LYVE1、TIMD4。
- scRNA-seq + CITE-seq（蛋白 + 转录本同测，n=4/时点）：区分驻留池耗竭 vs 功能抑制。
- 组织 ADAM17 活性（荧光底物 / 活性探针）与 sMER（ELISA）。

**Aim 1.3 人样本队列（临床锚定，本课题的核心资产）**
- **前瞻性急性心肌炎队列（目标 n=150，多中心，随访 12 个月）**
  - 采样时点：入院（d0–1）、d3、d7、1 个月、3 个月、6 个月、12 个月。
  - 测：血浆 **cf-mtDNA**（ddPCR，mtDNA/nDNA 比值 + 绝对拷贝）、**sMER**（ELISA）、**exopher 样囊泡**（纳米流式/成像流式，心肌源性用 cTnI/线粒体双标）、循环单核细胞膜 MERTK（流式）。
  - 终点：12 个月 LVEF 变化、是否符合炎症性 DCM、MACE、复发。
  - **主要分析**：d3–d7 的"清除失能指数"能否独立预测 12 个月 LVEF（校正 cTn 峰值、基线 LVEF、LGE）。
- EMB/移植心脏组织（n≥25）：MERTK/TREM2 免疫组化 + 心肌细胞线粒体形态（电镜）+ 巨噬细胞内线粒体物质。

**Aim 1.4 失衡的"分型"：F1 vs F3**
- 巨噬细胞**代谢组/脂质组**（NAD⁺、衣康酸、琥珀酸、游离胆固醇、酰基肉碱）→ 区分"抓不住（F1）"与"消化不了（F3）"。
- 理由：这两种故障需要完全不同的药（02 文档：选错靶点的主要风险）。TREM2–SYK–SLC25A53–NAD⁺–衣康酸轴（Cell Death Differ 2024）提供了 F3 的分子坐标。

### Aim 2　遗传学因果：清除失能是转归的决定变量（对应 H2）

| 小鼠工具 | 预期方向 | 作用 |
|---|---|---|
| `Mertk^fl/fl; Lyz2-Cre` 或 `Cx3cr1-CreER` | 加重慢性化、纤维化、mtDNA 池升高 | **必要性** |
| **`Mertk^CR/CR`（cleavage-resistant 敲入，剪切位点突变）** | **减轻**慢性化 → 直接证明"剪切"而非"表达量"是关键 | **本课题最有说服力的单个实验** |
| `Adam17^fl/fl; Lyz2-Cre` | 与 MertkCR 同向（保护） | 上游因果 |
| `Trem2^-/-` 或 `Trem2^fl/fl; Cx3cr1-CreER` | 加重 | 平行通路 |
| `Sting1^gt/gt`（goldenticket）或 `Sting1^fl/fl; Myh6-Cre` 与髓系 Cre | 若保护，则证明下游依赖 STING | **H3 的机制闭环** |
| `Mertk^fl/fl × Sting1^gt` 双突变 | Mertk 缺失的加重效应应被 STING 缺失**挽救** | **上位性（epistasis）实验——机制链条的决定性证据** |
| CCR2⁻ 驻留巨噬细胞特异耗竭（`Timd4/Lyve1` 系统或 CD169-DTR） | 加重 | 池身份归属 |

**模型与时间窗**
- **CVB3 急性→慢性**（d0 感染；d7/d14/d28/d60 取点）：必须同时测病毒载量（排除"保护只是因为病毒清除更快"）。
- **EAM 急性→慢性**（d21 峰值；d35/d60 慢性期）。
- **暴发性心肌炎模型**（高剂量 CVB3 或 EAM + 强化佐剂）→ 对应临床场景 B。
- **ICI 心肌炎模型** → 对应 Nat Commun 2024 的语境，用于证明本机制的**普适性**（而非仅病毒性）。

**关键读出**：CI（清除指数）、心脏/血浆 mtDNA、IFN 特征基因、纤维化面积、LVEF/GLS 轨迹、心肌细胞死亡、单细胞免疫图谱。

### Aim 3　成药：恢复清除（主线）+ 下游灭火（并联）（对应 H3，G5+G7）

**Aim 3.1 工程蛋白：抗剪切 sMERTK–GAS6 双功能分子（本课题的"新分子"资产）**

设计思路（三代递进，明确标注工程假设）：

| 版本 | 设计 | 解决什么 |
|---|---|---|
| **v1 诱饵清扫型** | 重组 **GAS6 Gla-缺失突变体**（保留 LG 结构域结合 MERTK，去除促凝/钙依赖膜结合）→ 竞争性占据 sMER，解除其诱饵效应，恢复膜 MERTK–GAS6 信号 | 直接针对"sMER 双重打击"中的第二击 |
| **v2 功能补充型** | **MERTK 胞外域–Fc 融合 + 磷脂酰丝氨酸（PS）结合模块（如 MFG-E8 C2 结构域 / Annexin V）** → 作为**桥接分子**，把暴露 PS 的 exopher/凋亡碎片直接连接到巨噬细胞 FcγR，绕过被剪切的 MERTK | 在 MERTK 已被剪切的情况下**重建桥接** |
| **v3 源头阻断型** | **ADAM17 剪切位点特异的封闭抗体**（抗 MERTK stalk 区）或 ADAM17 选择性抑制（优先抗体而非广谱金属蛋白酶抑制剂，避免 TNF 通路与既往 MMP 抑制剂的毒性教训） | 从源头保留膜 MERTK |

**计算设计环节（必要且不可替代）**
- **AlphaFold3 / 同类结构预测**建模 GAS6–MERTK、MFG-E8 C2–PS 膜界面、MERTK stalk–ADAM17 识别区；
- **分子对接 + 分子动力学**评估 v1 突变体保留 LG–MERTK 亲和力、丧失 Gla–膜结合；
- 抗体表位设计：定位 ADAM17 剪切位点附近的可及表位（而非催化位点，提高特异性）。

**Aim 3.2 髓系定向 mRNA-LNP：原位补充清除能力**
- 载荷：①抗剪切型 MERTK（剪切位点突变）全长；②TREM2（平行通路）。
- 递送：炎症期单核/巨噬细胞天然高摄取 LNP（比心肌细胞递送容易得多 —— 这是课题二在递送上的**先天优势**，与课题一形成技术互补而非竞争）；采用髓系偏好的离子化脂质配方 + 必要时表面配体（如甘露糖/抗 Ly6C）。
- **瞬时表达的优势**：与永久性遗传修饰相比，瞬时性在安全上更可控（这一逻辑已被 mRNA-LNP 瞬时 CAR-T 抗心脏纤维化工作验证，Science 2022）。
- 读出：心脏巨噬细胞转染效率（报告基因）、膜 MERTK 恢复、CI 改善、转归改善。

**Aim 3.3 老药新用：CMap/LINCS 驱动的"促清除"小分子**

```
Step 1  定义两个特征签名
        ① "清除失能签名"（来自 Aim1 人/鼠心脏巨噬细胞 scRNA-seq 的失能态）
        ② "持续点火签名"（IFN/STING 特征基因集）
                  │
Step 2  CMap/LINCS L1000 特征反转（以巨噬细胞/单核细胞系签名为优先匹配细胞背景）
        → 取负相关 Top 200 → 筛已上市/临床期 + 心脏安全可接受
        阳性对照类（文献已知促 efferocytosis）：糖皮质激素、他汀（RhoA 途径）、
        LXR 激动剂、4-PBA 等 —— 作为**筛选体系的质控**，而非结论
                  │
Step 3  体外功能筛选（关键：必须用真实底物，而非珠子）
        一级：人/鼠巨噬细胞 对**心肌细胞来源 exopher/损伤线粒体**的摄取率（高内涵成像）
        二级：吞噬后降解（pH 敏感探针）、IL-1β/IFN-β 释放
        三级：巨噬细胞–心肌细胞共培养中的心肌细胞存活
        反筛（强制）：是否只是广谱抗炎（测 LPS 诱导 TNF 的抑制，用于区分）
                  │
Step 4  对接验证候选的直接靶点（若机制不明）
        AlphaFold 结构 + 对接；必要时做热位移/光亲和标记确认靶点
```

**Aim 3.4 并联"灭火"：STING 核酸药（明确定位为联合而非主线）**
- *STING1*(*TMEM173*) ASO/siRNA，或小分子 STING 拮抗剂（工具：H-151 类）。
- 定位：①**机制证明**（H3 的药理学版上位性实验）；②**联合治疗**（恢复清除 + 下游灭火，检验是否协同）。
- **不作为主线的理由**：长期抑制 STING 可能损害抗病毒免疫（CVB3 模型中必须验证病毒载量）——这与课题一的治疗窗问题性质相同，必须前置评估。

### Aim 4　伴随诊断：把机制变成一张化验单（对应 G3+G5，本课题的最快转化点）

**产品定位**：急性心肌炎第 3–7 天的**转归预测试剂盒**（"清除失能指数"，Clearance Failure Index, CFI）。

**组成（三联，均为血液）**
1. **cf-mtDNA**：ddPCR 检测 mtDNA 特定区段（如 ND1/ND4，双靶标以控制缺失干扰），以 mtDNA/nDNA 比值报告。
2. **sMER**：可溶性 MERTK 胞外域（ELISA / CLIA）。
3. **心肌源性囊泡负荷**：纳米流式/成像流式，cTnI 或心肌特异标记 + 线粒体染料双阳性颗粒计数（探索性，作为第三代升级）。

**开发路径**
- 发现阶段（Aim 1.3 队列 n=150）→ 建立 CFI 模型（逻辑回归/机器学习，严格防过拟合：训练/验证分割 + 另一中心外部验证）。
- 预设性能目标：预测"12 个月 LVEF 未恢复至 >50%"的 AUC ≥ 0.80，优于 cTn 峰值 + 基线 LVEF 的基线模型（Delong 检验）。
- 分析验证：精密度、线性、干扰（溶血、脂血、抗凝剂）、稳定性、参考区间。
- **与药物同步开发**：CFI 阳性作为未来 II 期临床试验的**入组富集标准**——这是把 ARAMIS 的失败教训（入组未筛选的低危人群）直接转化为设计优势。

## 4.8 动物有效性与安全性验证（两课题共用标准，本课题特有项加★）

**有效性（必须是"治疗性"给药，不是预防性）**
| 模型 | 起始给药时点 | 主要终点 | 次要终点 |
|---|---|---|---|
| CVB3 急→慢 | d7（炎症已起） | d60 LVEF、纤维化面积 | CI 指数、心脏 mtDNA、IFN 特征 |
| EAM 慢性 | d21（峰值后） | d60 LVEF/GLS、炎症评分 | 同上 |
| 暴发型 | 发病后 48h | 30 天生存 + LVEF | 心肌细胞死亡、ECMO 替代指标 |
| ICI 心肌炎（+肿瘤） | 发病后 | 心脏表型 **+ 肿瘤体积** | 系统 T 细胞应答 |

**安全性（分层推进）**
1. **药理学安全（机制相关，最关键）**
   - ★**抗病毒免疫**：CVB3 载量（心、脾、胰）、再感染挑战、流感/LCMV 挑战 → 清除 DAMP 的治疗不应损害病原清除；
   - ★**促纤维化风险**：TREM2⁺ 巨噬细胞的衣康酸可促成纤维细胞增殖（Cell Death Differ 2024）→ 必须评估"增强清除"是否过度促纤维化（Masson + α-SMA + 胶原 I/III + 心肌硬度）；
   - ★**自身免疫风险**：MERTK 缺陷已知与系统性自身免疫相关（清除凋亡细胞障碍）→ 本课题是**增强**清除，方向相反，但工程蛋白的 PS 结合模块可能干扰正常凋亡细胞清除 → 测 ANA、抗 dsDNA、肾脏病理、脾/淋巴结;
   - ★**促凝风险**：GAS6 为维生素 K 依赖蛋白，与血小板功能相关 → v1 设计故意去除 Gla 结构域；必须做血小板聚集、凝血（PT/APTT）、血栓模型。
2. **一般毒理**：单次/重复给药毒性（小鼠 + 大鼠或猪）、免疫原性（抗药抗体 ADA，工程蛋白重点）、补体活化（LNP/核酸类重点）、注射部位、肝肾功能、血液学。
3. **心脏安全专项**：遥测 ECG（QTc、心律失常负荷）、心肌细胞钙瞬变与收缩（hiPSC-CM），ICH S7A/S7B 核心电池。
4. **大动物（猪）概念验证与安全**：
   - 模型：猪 CVB3 或免疫诱导心肌炎（或替代：猪缺血再灌注作为"DAMP 高负荷"的桥接模型，明确标注为替代模型的局限）；
   - 目的：剂量外推、心脏组织暴露、CMR 影像终点、大动物 ECG 安全、重复给药可行性；
   - 这一步对 **IND 前沟通**的说服力远高于只有小鼠数据。

## 4.9 风险识别与对策

| # | 风险 | 概率 | 影响 | 对策 |
|---|---|---|---|---|
| **R1** | 在体 exopher 定量方法建立失败（信号弱、难与细胞碎片区分） | **高** | **高（整个课题的方法学基石）** | ①多报告基因并行（mt-Dendra2 / mt-Keima / MitoTimer），其中 mt-Keima 可同时读出溶酶体酸化（吞噬后降解）；②以 ISO 应激为已发表的阳性对照校准方法；③纳米流式 + 成像流式 + 共聚焦三平台交叉；④**预留 6 个月方法学专项**并把该方法本身作为一篇方法学论文与专利（即使主假说有变，方法资产仍成立） |
| **R2** | 人队列 n=150、12 个月随访在周期内无法完成 | 中高 | 高 | ①采用**两段式**：先用已有生物样本库的回顾性病例（n≈60）做发现，前瞻队列做验证；②多中心（≥4 家）同时启动；③主要终点设在 6 个月并把 12 个月作为延伸分析 |
| **R3** | MERTK 剪切在人心肌炎中不显著（可能是 TREM2 或 F3 代谢故障主导） | 中 | 中 | Aim1.4 的 F1/F3 分型是**预先设计的分叉**：若为 F3 主导，则靶点切换到 TREM2–SYK–NAD⁺/衣康酸轴与 LXR/胆固醇流出，**L2/L3 框架与诊断产品（cf-mtDNA）完全不变** |
| **R4** | "增强清除"过度促纤维化，反而恶化结局 | 中 | 高 | 已列为强制安全读出（§4.8）；准备"时间限制性给药"方案（仅覆盖转归窗 2–4 周，避免长期增强）；设计上优选 v1/v3（恢复生理水平）而非 v2（超生理桥接） |
| **R5** | 工程蛋白免疫原性高 / 半衰期短 | 中 | 中 | 人源化设计、Fc 工程（延长半衰期、去除效应功能避免 ADCC）、去免疫原性表位预测；备选改为 mRNA-LNP 原位表达（Aim3.2 已并行） |
| **R6** | STING 阻断损害抗病毒免疫 | 中 | 中 | 已定位为"并联/联合"而非主线；设短程给药；CVB3 载量为强制读出 |
| **R7** | cf-mtDNA 特异性不足（任何组织损伤均升高） | **高** | 中高 | ①这是本诊断最大的技术风险，因此设计为**三联而非单指标**（sMER 提供"清除端"特异性，心肌源囊泡提供"器官"特异性）；②加入心肌特异归一化（与 hs-cTnI 比值，即"单位损伤对应的 DAMP 残留量"——这比绝对值更贴近"清除效率"的概念）；③设立非心脏炎症对照组（肺炎、脓毒症）做特异性验证 |
| **R8** | 大动物心肌炎模型不成熟 | 中 | 中 | 明确采用"替代模型 + 局限声明"策略，并把大动物主要用于**安全与 PK**而非疗效主张 |

## 4.10 Go / No-Go 决策点

| 时点 | 决策点 | Go 标准 | No-Go 后的转向 |
|---|---|---|---|
| M09 | Aim1.1 方法学 | CI 指数在 ISO 阳性对照中可重复（CV<20%），并能区分 d7 vs d28 | 转向"清除机器状态"为主读出（膜 MERTK/sMER/组织 mtDNA），放弃单颗粒收支定量 |
| M15 | 人队列发现阶段 | 进展者 d3–d7 的 cf-mtDNA/sMER 显著高于恢复者 | 诊断产品暂停；课题回落为纯机制研究 |
| M24 | Aim2 核心表型 | **Mertk^CR/CR 显著减轻慢性化** | "剪切"假说否定 → 切换到 TREM2/F3 轴（R3 分叉） |
| M30 | 上位性实验 | *Sting1* 缺失能挽救 *Mertk* 缺失的加重表型 | 机制链条改写（可能是 NLRP3 主导）→ 调整并联药物为 NLRP3 抑制剂（已上市/临床期分子更多，转化反而更快） |
| M36 | 工程蛋白 | 在 ≥2 模型中治疗性给药改善主要终点，且无促纤维化/促凝/自身免疫信号 | 切换到 mRNA-LNP 主线或老药新用主线 |
| M42 | CFI 性能 | 外部中心 AUC ≥0.75 | 诊断降级为"研究用途"，不申报 IVD |

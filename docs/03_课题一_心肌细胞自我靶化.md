# 课题一　心肌细胞"自我靶化"（Cardiomyocyte Self-Targeting）

## NLRC5–免疫蛋白酶体–MHC-I 轴把心肌细胞从被动受害者转变为主动抗原呈递靶标，驱动心肌炎慢性化与炎症性心肌病

---

## 3.1 L1 临床层：问题从哪来

### 3.1.1 三个真实的临床场景

**场景 A（病毒阴性慢性心肌炎 / 炎症性 DCM）**
45 岁男性，6 个月前"病毒性心肌炎"，当时 LVEF 48%。现 LVEF 降至 34%，CMR 示持续 T2 升高与新发 LGE。EMB：CD3⁺ 淋巴细胞密度升高、CD68⁺ 增多、**病毒基因组 PCR 阴性**。
→ 临床医生面对的问题：病毒已经没了，**炎症在打什么？** 要不要上泼尼松 + 硫唑嘌呤（TIMIC 方案）？若上，为什么有人有效有人无效？

**场景 B（ICI 心肌炎慢性/亚急性期）**
68 岁肺癌患者，PD-1 抑制剂第 2 周期后发生心肌炎，大剂量激素后 cTn 下降但未归零，4 周后 cTn 再次爬升。
→ 临床矛盾达到极致：**加强全身免疫抑制会让肿瘤失控，不加强会死于心肌炎。** 这个病人需要的是一个"只让心脏对 T 细胞隐形、不削弱全身抗肿瘤免疫"的药。
→ 正是这个矛盾，决定了本课题的靶点必须在**心肌细胞侧**而不是免疫细胞侧。

**场景 C（反复发作性心肌炎）**
28 岁女性，2 年内 3 次心肌炎样发作，每次 cTn 升高、胸痛、CMR 阳性，间期正常。
→ 为什么会**复发**？什么在心脏里"记住"了？（→ 心脏 TRM 与持续抗原呈递）

### 3.1.2 临床未满足需求（可量化）

| 需求 | 现状 | 缺口 |
|---|---|---|
| 慢性心肌炎的疾病修饰治疗 | 0 个获批药物；TIMIC 方案仅在病毒阴性亚组有效，且为广谱免疫抑制 | 需要**非广谱、不抑制全身免疫**的靶向策略 |
| ICI 心肌炎的"心脏特异性"治疗 | 激素 → 阿巴西普/芦可替尼（有效但全身性 T 细胞抑制） | 需要**器官限制性**干预 |
| 慢性期的机制分型 | 仅凭病毒 PCR 阴/阳 + 免疫组化细胞计数 | 需要**"炎症靠什么维持"**的读出 |
| 复发风险预测 | 无 | 需要抗原持续性/克隆持续性标志物 |

## 3.2 L2 病理生理层：把"进展"换成"过程"

**命题**：慢性心肌炎向炎症性 DCM 的进展 = **持续性心肌细胞净损失** > 代偿性重塑能力。

在慢性期（病毒已清除、急性 DAMP 风暴已过），持续杀伤的执行者是**抗原特异性细胞毒 T 细胞**。证据链：
1. T 细胞系统被确立为自身免疫性心肌炎与炎症性心肌病的主要始动者；
2. 心脏浸润 T 细胞是**抗原驱动、克隆性扩增、长期维持**的；
3. 损伤会播种肌球蛋白特异性 TRM，并把急性激活连接到慢性复发性炎症（ICI 心肌炎中已被证明）；
4. TRM 的维持**必须有同源抗原持续存在**（抗原 + IL-15 非冗余）。

**由此推出一个必然的、但被忽略的前提**：
> 细胞毒 T 细胞要杀心肌细胞，必须在**心肌细胞表面**看到 MHC-I/肽复合物。
> 因此 **心肌细胞自身的抗原加工呈递能力，是慢性期杀伤的"限速环节"与"靶标选择器"**。

**稳态命题（L2 的核心模型）**：
```
心肌细胞的"免疫可见度"（immune visibility）
      = f( MHC-I 表面密度 × 可呈递自身肽库的丰度与特征 )

慢性期杀伤速率 ∝ 免疫可见度 × 心脏 TRM 克隆负荷
```
现有全部治疗都在压低右侧第二项（TRM/T 细胞），**从未有人尝试压低第一项**。

## 3.3 L3 细胞生物学层：定位到一个保守的基本细胞过程

**对应的基本细胞过程：胞内蛋白质降解 → 抗原加工 → MHC-I 装载与转运（ubiquitin–proteasome → TAP → ER 装载 → 表面呈递）。**

这个过程在心肌细胞中有三个特殊性，构成本课题的生物学切入点：

| 心肌细胞特殊性 | 含义 | 为何重要 |
|---|---|---|
| ①**终末分化、不可替代** | 被杀一个少一个 | 任何"免疫可见度"的升高都是净损失 |
| ②**肌纤维蛋白占总蛋白极高比例**（α-MyHC 等） | 一旦蛋白降解通路被重编程，呈递肽库会**被肌纤维自身蛋白主导** | 直接解释为什么自身抗原是 α-MyHC——**不是因为"选择性自身免疫"，而是因为"底物丰度"**（本课题的核心新概念之一） |
| ③**基础 MHC-I 表达低、但 IFN-γ 高度诱导** | 心脏在稳态下是"免疫特惠"器官 | 一旦被诱导，相当于从"隐形"切换到"高亮"——是一个**开关式**事件，适合做干预 |

**开关在哪？**
- IFN-γ → JAK1/2–STAT1 → **NLRC5（CITA）** → 反式激活 **MHC-Ia / MHC-Ib / B2M / PSMB9(LMP2) / PSMB8(LMP7) / TAP1** 这一整套抗原呈递模块。
- 同时 PSMB8/PSMB9/PSMB10 组装成**免疫蛋白酶体**，改变切割偏好（产生疏水 C 端肽），**定性地改写呈递肽谱**。
- 即：**NLRC5 是"总开关"，免疫蛋白酶体是"肽谱改写器"**。二者在肿瘤与感染免疫中已确立，但**心脏/心肌细胞中 NLRC5 的功能完全空白**（见 01 文档 §1.8）。

## 3.4 中心假说

> **假说（Self-Targeting Hypothesis）**
> 在心肌炎的慢性期，心脏内持续的 IFN-γ 信号经 **STAT1–NLRC5** 轴在**心肌细胞自身**中建立一个稳定的"抗原呈递程序"（MHC-I^hi + 免疫蛋白酶体^hi + TAP1^hi）。该程序：
> （i）把高丰度肌纤维蛋白（以 α-MyHC 为代表）定向加工为具有免疫蛋白酶体切割特征的自身肽，**改写心肌细胞免疫肽组**；
> （ii）将心肌细胞由被动受害者转变为**主动的、持续的抗原呈递靶标**，为心脏 TRM 提供维持所必需的同源抗原与杀伤坐标；
> （iii）由此形成 **"杀伤 → IFN-γ → 更高可见度 → 更多杀伤"的前馈环**，这是慢性化与向炎症性 DCM 进展的核心驱动。
>
> **治疗推论**：**心肌细胞特异性地关闭这个程序（而不抑制全身免疫），可以在不削弱系统抗病毒/抗肿瘤免疫的前提下，切断慢性期的心肌细胞净损失。**

### 3.4.2 三个可证伪的子假说

| 子假说 | 证伪条件 |
|---|---|
| **H1（存在性）** 人慢性心肌炎/炎症性 DCM 心肌中存在"抗原呈递程序高开"的心肌细胞亚群，且与克隆性 CD8 TRM 空间毗邻 | snRNA-seq 未发现该亚群，或空间上与 CD8 无富集关系 |
| **H2（必要性）** 心肌细胞特异性 *Nlrc5* 缺失可降低 MHC-I 呈递、减少 CD8 介导的心肌细胞死亡、减轻慢性期炎症与心功能下降 | 条件敲除小鼠慢性期表型无改善（或恶化，提示 NLRC5 在心脏另有保护功能） |
| **H3（充分性/可干预性）** 在**已建立**的慢性心肌炎中，心肌细胞定向抑制该程序（siRNA/ASO 或选择性免疫蛋白酶体抑制剂）能改善结局，且**不损害系统性抗病毒/抗肿瘤免疫** | 干预无效，或导致病毒复燃/肿瘤加速生长（则治疗窗不成立） |

## 3.5 研究内容：四个 Aim

### Aim 1　在人类组织中建立"自我靶化"表型，并证明它与克隆性 CD8 TRM 空间耦合（对应 H1，G1+G2）

**核心产出**：人慢性心肌炎心肌细胞的"自我靶化评分（Self-Targeting Score, STS）"及其与 CD8 TRM 微龛的空间证据。

**样本设计（关键，决定整个课题的说服力）**

| 组别 | n（目标） | 来源 |
|---|---|---|
| 急性心肌炎（≤4 周，EMB） | 15 | EMB 剩余组织 |
| **慢性心肌炎/炎症性 DCM（病毒阴性）** | 25 | EMB + 移植时心脏 |
| 慢性心肌炎（病毒持续阳性） | 10 | 作为机制对照 |
| ICI 心肌炎 | 10 | 多中心协作（含尸检） |
| 非炎症性 DCM | 15 | 移植心脏 |
| 正常对照 | 12 | 弃用供心 |

**方法与读出**
1. **snRNA-seq（10x，心肌细胞核）+ scRNA-seq（CD45⁺ 分选）+ 配对 scTCR-seq**：
   - 心肌细胞端：定义 `MHC-I^hi / PSMB8^hi / TAP1^hi / NLRC5^hi` 程序，构建 STS（基于模块评分，含 HLA-A/B/C、B2M、PSMB8、PSMB9、TAP1、NLRC5、IRF1、STAT1）。
   - T 细胞端：TRM 表型（CD69、ITGAE、CXCR6、PDCD1）+ **克隆性指数**（Gini/Shannon），判定抗原驱动。
2. **空间转录组（Xenium / CosMx，定制 panel）+ 多重免疫荧光**：量化"MHC-I^hi 心肌细胞 – CD8⁺CD69⁺ T 细胞"的**最近邻距离分布**，与随机置换零模型比较 → 建立"杀伤微龛（killing niche）"。
3. **免疫组化/免疫荧光定量**：心肌细胞膜 HLA-ABC 密度（以肌膜 dystrophin 共定位界定），避免把浸润细胞的 MHC-I 误计。
4. **临床相关性**：STS vs LVEF 变化轨迹、LGE 范围、复发次数、是否进展为 DCM（回顾性 + 前瞻性随访）。

**判定标准（预设）**：慢性病毒阴性组 STS 显著高于急性组与非炎症 DCM 组；STS 与 CD8 克隆性指数正相关（r>0.5）；MHC-I^hi 心肌细胞周围 CD8 密度显著高于随机。

### Aim 2　确定"开关"并解码被改写的免疫肽组（对应 H1→H2 桥梁，G2）

**Aim 2.1 从候选调控子收敛到 1–2 个"开关"：虚拟敲除**
- 用 Aim 1 的 snRNA-seq（+ 配套 snATAC-seq，n=8）构建心肌细胞**基因调控网络（GRN）**。
- 用 **CellOracle** 类方法对网络中全部候选转录调控子（预计 20–40 个，含 NLRC5、STAT1、IRF1、IRF2、CIITA、RFX5、NFKB1 等）做**in silico knockout**，评估"整个抗原呈递模块坍塌程度"与"细胞状态向量迁移方向"。
- **目的**：把需要做条件敲除小鼠的候选从 ~30 降到 2–3（这是本技术唯一且不可替代的作用，见 02 文档 §2.4）。
- 预期首位节点：NLRC5；备选：IRF1（若 NLRC5 在心肌细胞中不主导，则假说需修正，见风险对策 R2）。

**Aim 2.2 免疫肽组学：回答"到底呈递了什么"（本课题最硬的创新点）**
- 体系：
  - (a) **hiPSC-CM**（≥3 供者，含 HLA-A*02:01 与 HLA-A*24:02 等常见型别）± IFN-γ（±TNF-α）长时程刺激（0 / 24h / 7d / 14d，模拟慢性暴露）；
  - (b) **人移植心脏组织**（炎症性 DCM vs 非炎症 DCM，各 n≥4，≥0.5 g）。
- 方法：pan-HLA-I（W6/32）免疫亲和纯化 → 酸洗脱肽 → **DIA/DDA LC-MS/MS**（高分辨 Orbitrap）→ 肽谱鉴定与 HLA 型别去卷积（NetMHCpan 辅助）。
- **关键分析（三问）**：
  1. **来源偏倚**：呈递肽是否显著富集于肌纤维/肌小节蛋白（MYH7/MYH6、TNNT2、ACTC1、DES、TTN）？→ 检验"底物丰度决定自身抗原"这一新概念。
  2. **切割特征**：IFN-γ 诱导后肽的 C 端是否转向疏水残基（免疫蛋白酶体切割特征）？→ 直接证明肽谱被"改写"而非只是"变多"。
  3. **依赖性**：在 hiPSC-CM 中 siRNA 敲低 NLRC5 或加选择性免疫蛋白酶体抑制剂后，上述改写是否被逆转？
- **输出**：一份"**人心肌细胞 IFN-γ 诱导性自身肽图谱**"——这是**可申请专利并可长期复用的资产**（诊断抗原、耐受诱导肽、TCR 发现的来源）。

**Aim 2.3 生化重构（机制而非相关）**
- 体外重组免疫蛋白酶体 vs 组成型蛋白酶体，对纯化 α-MyHC 片段/合成底物做**体外酶切 + 质谱**，验证切割位点偏好与候选表位的产生依赖免疫蛋白酶体。
- CUT&RUN / ChIP-qPCR 验证 NLRC5 在人/鼠心肌细胞 *HLA-A/B2M/PSMB8/TAP1* 启动子的占据与 IFN-γ 依赖性。

### Aim 3　遗传学因果与人源功能验证（对应 H2，G8）

**Aim 3.1 心肌细胞特异性遗传操作（因果核心）**

| 工具 | 构建 | 用途 |
|---|---|---|
| `Nlrc5^fl/fl ; Myh6-MerCreMer` | 他莫昔芬诱导型、**心肌细胞特异**、**可在疾病建立后再敲除**（治疗性时序，而非出生即缺失） | H2 必要性 + 治疗时序可行性 |
| `Nlrc5^fl/fl ; Myh6-MerCreMer ; Psmb8^fl/fl` 双敲 | 区分"MHC-I 数量"与"肽谱定性" | 机制解析 |
| AAV9-cTnT-shNlrc5 / AAV9-cTnT-dCas9-KRAB | 不依赖品系，可用于多种模型与大动物预试 | 工具冗余（降低品系风险） |
| 心肌细胞特异性 **MHC-I 过表达**（AAV9-cTnT-H2-Kb + 模型抗原） | **充分性**：在无感染条件下人为升高免疫可见度，是否足以在有 TRM 的心脏引发持续损伤 | 关键的"反向实验" |

**疾病模型（三个，覆盖不同病因）**
1. **CVB3 慢性心肌炎**（A/J 或 BALB/c，感染后 28–60 天）→ 病毒性/后病毒性慢性化；必须同时测**病毒载量**以确认不削弱清毒（治疗窗核心安全问题）。
2. **EAM（α-MyHC 肽 + CFA，BALB/c）**，取**慢性期（d35–d60）**→ 自身免疫性，无病毒混杂。
3. **ICI 心肌炎模型**（如 *Ctla4*^+/−*Pdcd1*^−/− 或 PD-1 阻断 + 肌球蛋白致敏）→ 对应临床场景 B，且可**同时植入肿瘤**检验"心脏保护 vs 抗肿瘤免疫保留"。

**读出矩阵**（全部模型统一）
- 心功能：超声（LVEF、GLS）、有创压力容积环（终点）、心脏 MRI（选）
- 组织：H&E 炎症评分、Masson 纤维化、TUNEL/cCasp3、心肌细胞横截面积
- 免疫：流式（CD8 TRM、Treg、CCR2⁺/CCR2⁻ 髓系）、心脏单细胞（关键组）
- 分子：心肌细胞膜 MHC-I 密度（流式/IF）、免疫蛋白酶体活性（活性探针）、IFN 特征基因
- 安全/治疗窗：**病毒载量**（CVB3 模型）、**肿瘤体积**（ICI 模型）、脾/淋巴结 T 细胞应答（系统免疫是否保留）

**Aim 3.2 人源体系（跨越 G8）**
- **hiPSC-CM + 抗原特异性人 T 细胞共培养杀伤实验**：
  - T 细胞来源：(a) 患者外周血扩增的 TRM 样 CD8（HLA 匹配）；(b) 用 Aim 2 鉴定表位 + 患者 TCR 序列构建的 **TCR 工程 T 细胞**（最严格的抗原特异性证据）。
  - 读出：实时阻抗/钙成像、LDH/cTnI 释放、活细胞成像的杀伤动力学。
  - 干预：NLRC5 siRNA / 免疫蛋白酶体抑制剂 / HLA-I 抗体封闭（阳性对照）。
- **人心脏切片培养（living myocardial slices）**（若可获得移植心脏）：在保留原位免疫浸润的组织中检验干预效果——**最接近人的体外体系**。

### Aim 4　成药：老药新用 + 心肌细胞定向核酸药物（对应 H3，G5+G7）

**Aim 4.1 虚拟 + 实验药物筛选（CMap/LINCS → 对接 → 细胞验证）**

```
Step 1  定义"自我靶化特征（Self-Targeting Signature, STsig）"
        来自 Aim1 人组织 + Aim2 hiPSC-CM IFN-γ 诱导的上/下调基因集（各 ~150 基因）
                  │
Step 2  CMap / LINCS L1000 特征反转查询
        约 3 万化合物签名 → 连接性评分 → 取负相关 Top 200
        交叉筛选：① 已上市/已进入临床 ② 心脏安全性可接受 ③ 机制可解释
                  │
Step 3  靶点–化合物对接验证
        - PSMB8（β5i）催化口袋：对接 + MM/GBSA 重打分（阳性参照：已进入临床 II 期的
          选择性免疫蛋白酶体抑制剂类分子；工具参照：ONX-0914/PR-957）
        - JAK1/2、STAT1 二聚界面：对接评估（作为"上游"备选，但需警惕全身免疫抑制）
                  │
Step 4  细胞层面实验筛选（hiPSC-CM，384 孔）
        一级读出：IFN-γ 诱导的膜 HLA-ABC（高内涵成像）
        二级读出：免疫蛋白酶体活性探针、PSMB8/TAP1 qPCR
        三级读出：hiPSC-CM–T 细胞共培养杀伤抑制率
        反筛（必须）：对 T 细胞自身活化/增殖的影响（排除"其实是全身免疫抑制剂"）
                  │
Step 5  成药性与心脏安全早筛
        hERG、心肌细胞收缩/钙瞬变（排除致心律失常）、线粒体毒性、细胞活力
```

**预设的"最佳情形"**：一个**已进入临床（如自身免疫病 II 期）的选择性免疫蛋白酶体抑制剂**在上述筛选中胜出 → 可走**适应证扩展**路径，是全链条中最快的转化点（见 06 文档）。
**预设的"兜底情形"**：若所有小分子均不能在不抑制 T 细胞的前提下降低心肌细胞免疫可见度 → 必须靠核酸药物（Aim 4.2），这也是我们把核酸药物作为并行主线而非备选的原因。

**Aim 4.2 NLRC5 核酸药物（本课题的"新分子"资产）**
1. **序列发现**：人/鼠 *NLRC5* mRNA 全长 ASO walk（GapmeR，约 80–120 条）+ siRNA 池（约 60 条）→ hiPSC-CM 与鼠原代心肌细胞中筛 IC50 与跨种保守先导。
2. **化学优化**：
   - ASO：PS/MOE/cEt 混合骨干，筛选低 RNase H1 介导肝毒性与低促炎（TLR9）序列；
   - siRNA：2'-OMe/2'-F + PS 末端，**种子区脱靶**最小化（seed-based off-target 计算 + 转录组验证）。
3. **递送（三路并行，见 02 文档 §2.5）**：
   - 主路径：**二十二碳酸（DCA）等脂肪酸共轭 siRNA**——该化学已被证明可功能性、安全地递送至骨骼肌与心肌；
   - 备选：心肌/炎症靶向配体修饰 LNP；
   - 工具：AAV9-cTnT-shRNA（仅机制验证与大动物概念验证）。
4. **PK/PD**：心肌组织药物浓度（LC-MS）、靶基因敲低深度与时长（≥4 周单次给药目标）、剂量-效应。
5. **有效性**：在 **已建立的慢性心肌炎**（CVB3 d28 起始给药；EAM d21 起始；ICI 模型发病后给药）中评价 → **治疗而非预防**，这是审稿人与评审最关心的。
6. **安全性与治疗窗（本课题的成败关键）**：
   - **抗病毒免疫是否保留**：CVB3 再感染挑战、流感/LCMV 挑战实验，测病毒清除动力学与抗原特异性 CD8 应答（脾/肺）；
   - **抗肿瘤免疫是否保留**：ICI 模型中同时植入 MC38/B16 肿瘤，测肿瘤生长；
   - 肝/肾毒性（ASO 类效应）、补体活化、细胞因子释放、血小板、注射部位反应；
   - 心脏电生理：遥测 ECG（QTc、心律失常负荷）；
   - 组织病理全套 + ICH S7A/S7B 核心电池（GLP 阶段）。

**Aim 4.3 伴随诊断原型**
- **组织端**："自我靶化评分" 的简化版（IHC 三联：HLA-ABC 膜密度 + PSMB8 + 心肌细胞标记），可在常规 EMB 蜡块上做 → **最容易落地的 IVD/LDT**。
- **外周端**：外周血 TCRβ 克隆性 + 可溶性 HLA-I / β2M；血浆中候选自身肽–MHC 四聚体反应性 T 细胞频率（探索）。
- **影像端（探索）**：免疫蛋白酶体活性或 MHC-I 的 PET 示踪剂可行性评估（仅做文献与化学可行性论证，不列入关键路径）。
